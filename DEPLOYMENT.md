Deploy frontend and backend separately. Set FRONTEND_ORIGINS to your actual frontend origin(s), comma separated (no trailing slash). Update public/elite-core.js API_BASE_URL to your backend HTTPS origin. Backend persists JSON at DATA_FILE; hosting MUST mount a persistent writable volume at the containing directory. Deploy backend before frontend. Re-login after publishing; new browser sessions use bearer tokens in sessionStorage. The login token is session-scoped and logging out clears it. Never put JWT_SECRET or ADMIN_PASSWORD in the frontend. Keep backups of JSON and run a single backend instance per file. No blockchain deposits automatically credit balances.
